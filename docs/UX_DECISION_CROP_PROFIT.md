# UX kararı — Ürünlerin durumu

## Amaç
Çiftçi toplam defterin yanında hangi ürünün para kazandırdığını muhasebe bilgisi olmadan anlayabilsin.

## Akış
Benim Defterim → Ürünlerin durumuna bak → ürün kartları → Deftere dön

## Kart dili
- Ürün adı
- Kalan
- Giren
- Çıkan

## Anayasa kontrolü
- Ana gelir/gider kaydına zorunlu dokunuş eklenmez.
- Teknik muhasebe terimi yok.
- Tek ekranda tek iş: ürünlerin parasal durumunu görmek.
- Offline çalışır; yalnız yerel şifreli veritabanını okur.
- Ürünle ilgisiz seçenek yok.
- Genel kayıtlar ürüne zorla dağıtılmaz.
- Hata halinde ham teknik mesaj gösterilmez.
